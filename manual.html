シナリオ整形ツール 取扱説明書

最終更新: 2026-09-29

  • シナリオのPDFまたは.txtのファイルを読み込むとシナリオ文章を編集できる
  • 本ツールで書き出したHTMLファイルを読み込めば続きの編集・プレビューもできる
  • ヘッダーから編集タブとプレビュータブを切り替えて使用。例:準備中は編集タブ、セッション中はプレビュータブ
  • 読み込んだシナリオの内容はすべて端末内で処理される。どこかのサーバーに送信されることはない

ファイルの読み込み

  • 画面上部の「ファイルを選ぶ」から次のいずれかを選ぶ
    • シナリオのPDFファイル
    • シナリオのTXTファイル
    • このツールで書き出したHTMLファイル(続きの編集用)
  • 複数ファイルをまとめて選ぶこともできる。選んだ順に上から連結して1本の本文として扱われる(シーンごとに分かれたTXTファイルなどをまとめて読み込みたいとき用)。PDF・TXT・本ツールのHTMLを混在させて選ぶこともでき、HTMLが含まれる場合はその見出し・NPCなどの設定も引き継がれる
  • PDFとTXTの両方が手に入る場合はTXT版を優先しておすすめ(PDFはレイアウトによって行の抽出順序が乱れることがあるため)
  • PDFを読み込むと、読みやすい本文になるよう次の整理が自動で行われる
    • 全ページの同じ位置に繰り返し出てくる章目次・柱(ページ端のインデックスなど)とページ番号は取り除かれる
    • 本文の横に付いたメモ欄・囲み(KP情報など)は、本文と1行ずつ混ざらないよう、横にある本文の文が終わったところ(または段落の切れ目)の直後にまとめて入る。左右が同じくらいの幅の2段組は左の段→右の段の順に読む
    • 改ページや手動の改行で文の途中が切れている場合は、1つの文としてつながる。見出し記号(■▼〇【など)で始まる行、「項目名：値」の行、文字の大きさが違う行はつながない。行間が大きく空いているところは段落の区切りになる
    • 字間・日本語と英数字の間などに入った余計なスペースは取り除かれる(「天竺 一」のような、名前の姓と名の間などのスペースは残る)。KP・PL・KPC・PC・RP・HO・GM・NPCの字間も詰められる
    • 見た目は同じでも検索で引っかからない特殊な漢字(部首用の文字「⾒」「⻑」など)は、通常の漢字に置き換えられる
    • 本文の文字の真上に乗った小さい文字はルビとみなして取り除く
  • PDFで再現できないもの: フローチャートなど図の中の文字の配置、英字の字間スペース(「P r e f a c e」など)、縦書きのPDF。気になる箇所は読み込んだあと編集タブで直す
  • 空行があるところで段落が変わる。 空行なしで続いている行は、同じ段落の中の詰まった改行として読み込まれる(段落の間にだけ余白が入るので、プレビューが読みやすくなる)

自動保存と「前回の続き」

  • 編集内容は、変更が止まって数秒後にこのブラウザ内へ自動保存される。保存の操作は不要
  • 次に開いたとき、読み込み画面に「前回の続き」として保存済みのシナリオが一覧で出る。「復元」を押せば続きから再開できる。不要なものは「削除」で消せる
  • 直近5シナリオ分まで保持される。それを超えると古いものから自動的に消える
  • これがあるので、作業途中に一時保存としてHTMLを書き出す必要はない。 書き出しは完成版をセッションで使うときだけでよく、フォルダにファイルが溜まらない
  • ただし保険として考えること。 iPhoneのSafariは、しばらくサイトを使わないと保存データを自動的に消すことがある。区切りがついたらHTMLに書き出しておくのが安全
  • プライベートブラウズなど、ブラウザの保存機能が使えない状態では自動保存は働かない(編集自体は普通にできる)

編集タブ

  • 一般的なメモアプリ等と同じようにテキストを編集できる
  • 本文中の好きな範囲を、段落をまたぐ範囲も含めて自由にドラッグ選択できる
  • 改行と段落の使い分け: Enter1回で「詰まった改行」(行間に余白が入らない)、Enter2回で「段落が変わる」(行間に余白が入る)
    • 地の文のように続けて読ませたい部分は改行、場面や話題が変わるところは段落、と使い分けるとプレビューが読みやすくなる
    • あとから改行を段落分けに変えたくなったら、その改行の直後(次の行の先頭)にカーソルを置いてEnterを1回押す。Enterを素早く2回押す必要はない。改行の直前(前の行の文末)でEnterを押した場合は、改行がもう1つ増える(段落分けにはならない)
    • 見出しの末尾でEnterを押すと、1回で見出しのすぐ後ろに本文の段落ができる(見出しの中には改行は入らない)
    • 見出しは常に1つの段落として独立する。見出しの直後がコピー範囲のとき、コピー範囲の先頭でバックスペースを押しても見出しとはつながらない
    • 段落分けをやめたいときは、次の段落の先頭にカーソルを置いてバックスペースを押す。1回目で前の段落の末尾に改行した状態でつながり、もう1回押すと改行も消えて文章がつながる
    • コピー範囲の先頭でバックスペースを押すと、直前の文章(同じ段落の直前の1行、または直前の段落)がコピー範囲の中に取り込まれる。こちらも1回目は改行した状態、2回目で1行につながる
    • 本文をコピーして貼り付けると、この段落と改行の区別がそのまま再現される
  • 上部リボンのボタンは左から「元に戻す」「検索」「空行挿入」「見出し」「ワンクリックコピーボタン設置」「分割」「NPCカード化」「リンク」「太字」「イタリック」「下線」。太字・イタリック・下線以外はアイコンのみの表示で、PCではマウスを乗せるとボタン名が表示される
  • リボンは画面をスクロールしても常に画面上部に表示される(iPhone/iPadでキーボードを出している間も含む)
    • 「元に戻す」: 直前の編集操作を1つ取り消す(最大20件さかのぼれる)
    • 「検索」: シナリオ内の単語を検索・置換できる
      • 検索窓に文字列を入力して「検索」(Enterでも可)。一致箇所はすべて色つきでマークされ、「↑」「↓」で前後の一致箇所に順番に移動できる
      • 置換したい場合は下段の入力欄に置換後の文字列を入力し「一括置換」。検索欄の文字列がそのまま置換対象になるので入力し直す必要はない
      • 検索・移動だけなら本文は書き換わらないので「元に戻す」の対象にはならない。プレビュータブに切り替えると検索バーは自動的に閉じる
      • マークは、本文をタップしたりカーソルを合わせたりしただけでは消えない。一致箇所を順に見て回っている間はそのまま残る
      • マークが消えるのは「実際に文字を入力したとき」「見出し化や文字装飾を適用したとき」「検索バーを×で閉じたとき」の3つ
    • 「空行挿入」: カーソル位置に実際の空行(空の段落)を1つ挿入する。シーンの区切りなど、通常の段落の余白よりさらに広い間隔を意図的に入れたいときに使う。カーソルの位置に挿入される。段落の途中にカーソルがあれば、その位置で段落が2つに分かれて間に空行が入る。段落の先頭ならその前に、末尾ならその後に入る。見出しの中にカーソルがあるときは、見出しを分けずに見出しの後ろに入る
      • コピー範囲の先頭で押すと、コピー範囲の直前に空行が入る
      • 複数段落のコピー範囲の途中で押すと、空行もコピー範囲の一部として入る(コピー範囲は分かれない)。空行に文章を書かないまま残しても、コピーボタンでコピーされる文章では通常の段落の区切りと同じ空行1行になる
    • 「分割」: コピー範囲の中にカーソルを置いて押すと、その位置でコピー範囲を2つに分ける(それぞれにコピーボタンが付く)
      • 段落の途中にカーソルがあれば、その位置で段落ごと分かれる。段落の先頭・末尾にカーソルがあれば、文章は分けずにその段落の前・後ろの境目で分かれる
      • ボタンは、コピー範囲の中にカーソルがあるときだけ押せる(文字を範囲選択している間は押せない)
      • コピー範囲の先頭・末尾では分割できない(案内が表示される)
      • 「元に戻す」で分割前に戻せる
    • 「見出し」: 選択した文章を見出しにする(見出しの階層は後述の「アウトライン」で調整)
    • 「ワンクリックコピー」: 選択範囲を一括でコピーできるボタンを設置する
      • 複数行にまたがる範囲をコピーすると、行の間に空行が入った状態で貼り付く(ココフォリアに貼ったときの見た目をツール上の表示に近づけるため)
      • コピー範囲の中でも、通常の本文と同じくEnter1回で段落が変わる
      • 本文を手でコピーした場合は空行は入らず、コピー元と同じ見た目で貼り付く
    • 「NPCカード化」: NPCのステータス情報が書いてある部分を選択して押すとNPCをカードにでき、ココフォリアの駒/チャパレへと出力できる
      • 技能は名詞＋パーセンテージ(例:回避 32%)のような形になっていれば拾う
      • スペース区切りなし、半角全角スペース、コロンでも◯。1行に複数並んでいてもOK(例:目星 25％ 聞き耳 30％)。＜技能名＞数値形式(例:＜回避＞32)もOK
      • ⚠この形から外れると読み取れない。うまく認識されないときは、本文側をこの形に整えてから改めて試す
      • 抽出がうまくいかなくても選択した全文はプロフィール欄にそのまま残るので手動で修正できる
    • 「リンク」: 選択範囲に見出しまたはNPCカードへの内部リンクを設定する。押すとリンク先の一覧(ピッカー)が開くので1件選ぶ
      • 編集タブでリンクをクリックしても何も起きない(誤操作防止のため)
      • プレビュータブでクリックすると、見出しへのリンクはトグルを開いてスクロール、NPCカードへのリンクはNPCパネルを開いて該当カードまでスクロール・一時ハイライトする。書き出したHTML(単体ファイル)でも同じ動作
    • 「太字」「イタリック」「下線」: 選択範囲に装飾を適用する
    • 見出し・ワンクリックコピー・太字/イタリック/下線は、設定済みの範囲を選び直して同じボタンをもう一度押すと解除できる(見出しを解除しても配下の本文は残る)
  • 右上の三本線からメニューが呼び出せる
    • 書き出し: HTMLはセッションで使う本番用。もう一度このツールに読み込めば編集もプレビューもできる(下記＜書き出したHTMLの読み込み＞参照)。MarkdownはNotionに読み込んで記録用に。txtは手元で見たい時に
      • 作業途中の保存は自動保存に任せられるので、書き出しは区切りがついたときだけでよい(上記＜自動保存と「前回の続き」＞参照)
      • ファイル名は「元のファイル名_整形.html」「元のファイル名_記録用.md」「元のファイル名_記録用.txt」の形式で自動的に付く
      • Markdownはすべての階層の見出しがNotion上で「トグルリスト」(折りたたみ可能な箇条書き)として展開される。見出しブロックではなくトグルリストになる点に注意。下線のNotion上での見え方は未検証(わかりません)
      • NPCカード・ワンクリックコピーボタンはMarkdown・txtの書き出しには含まれない
      • HTMLの上書き保存(PCのChrome/Edgeのみ): 初回の「書き出す」で保存先を選ぶと、以降はボタンが「上書き保存」に変わり、同じファイルを上書き更新する。一時保存のたびにファイルが増えないので、フォルダが散らからない
        • 保存先のファイル名はボタンの下に表示される。別のファイルに分けたいときは「別名で保存」
        • 前回保存したHTMLをこのツールに読み込み直すと、保存先も自動的に引き継がれる(別のシナリオを読み込んだときは引き継がない)
        • ブラウザを開き直したあとの初回保存では、ブラウザから書き込み許可の確認が一度だけ出る(ブラウザの仕様で省略できない)
        • iPhone・iPad(Safari)とFirefoxはこの仕組みに非対応。その場合は従来通り毎回新しいファイルとしてダウンロードされる
      • 共有して保存(iPhone・iPad向け): iOSの共有シートを開き、「ファイルに保存」で保存先フォルダを選んで保存できる。ダウンロードフォルダ以外に置きたいときに使う
        • iPhoneでは上書き保存はできない。ファイルを増やしたくない場合は、上記＜自動保存と「前回の続き」＞を使い、書き出しは完成版だけにするのがおすすめ
    • アウトライン: メイン画面で見出しを設定するとここに見出しが一覧化される。見出しごと移動したい時や見出しの階層をいじりたいときはここ
      • 見出し名の編集、削除・上下への移動、階層レベルの変更(インデント・アウトデント)ができる
      • 見出し化した直後はすべて同じレベルで並ぶので、大見出し・小見出しの関係はここで手動で組み立てる。この階層構造が書き出すHTMLのトグル(開閉可能な見出し)の入れ子構造にそのまま反映される
      • 各見出しの「→」ボタンを押すと、メニューが閉じて本文中のその見出しの位置までスクロールする(編集タブから見出しの場所へジャンプしたいとき用)
    • NPC管理: シナリオ中のNPCのステータス部分を選択し、NPCカード化のボタンを押すとNPCカードがここに追加される。ここで追加したカードはプレビュー画面で一覧可能
      • 「＋NPCを追加」から、空のNPCカードを作成できる（シナリオ本文には登場しない継続NPCなどに）
      • NPCごとに判定コマンドのバージョン(6版CCB/7版CC)を選べる。あとから変更すると既存の技能行のうち単純なコマンド表記は自動で新しい版に置き換わる(独自表記の行は対象外)
      • カードに含められるのは能力値・技能値・プロフィール文。画像は扱わない
    • ファイルの追加読み込み/入れ替え: 追加読み込みしたファイルは後ろに連結される(ファイルが複数にまたがるシナリオ用)。読み込むファイルの入れ替えも可能(現在の編集内容を破棄するため確認ダイアログが出る)

プレビュータブ

  • リボンなど編集用の要素が隠れ、実際にセッションで使う見た目・動作だけが表示される
  • 目次: ハンバーガーメニューから開ける「目次」で見出しの階層構造に沿ってページ内をジャンプできる。画面幅900px以上(PCやiPadの横向きなど)では常時表示のサイドパネルになる
  • NPCカード: ハンバーガーメニューの「NPCカード」から閲覧できる。各カードに「📋チャットパレットをコピー」(プレーンテキスト形式)と「📋ココフォリア駒出力」(ココフォリアに直接ペーストして駒を生成するJSON形式)の2つのコピーボタンがある
  • ワンクリックコピーボタン: 編集タブで設置した範囲の直後に常時表示される。地の文の読み上げ箇所やSAN値喪失の描写など、その場でコピーしたい範囲に使う
  • トグル見出し: シーンやエンディングなどの見出しをタップすると配下の本文が開閉する

書き出したHTMLの読み込み

  • 「HTML(セッション用)」で書き出したファイルは、そのまま「ファイルを選ぶ」から再度読み込める
  • 見出し階層・NPCカード・ワンクリックコピーボタンの設置位置・文字装飾・内部リンクなど、書き出した時点の構造がそのまま復元され、続きから編集できる
  • Markdown・txtは記録専用のため、このツールへの読み込みには対応していない

対応環境・注意点

  • 対応ブラウザ: iPhone・iPadのSafari、およびPC・Androidの一般的なブラウザ
  • 通信は発生しない: 読み込んだシナリオの内容は端末内でのみ処理され、外部サーバーには送信されない
  • ダークモード: 端末の設定がダークモードの場合、自動的に配色が切り替わる
  • セキュリティ: 他ツールで書き出したものを含め、読み込むHTMLファイルは内容を安全化(サニタイズ)したうえで取り込む。書き出すHTMLにもセキュリティ対策(CSP)を付与している

うまくいかないときは

  • PDFを読み込んだが文章の順序がおかしい・変な位置で改行される → 段組み・メモ欄・改ページはある程度自動で整理されるが(上記＜ファイルの読み込み＞参照)、図の中の文字や特殊なレイアウトでは抽出順が乱れることがある。TXT版が入手できる場合はそちらを優先し、ない場合は編集タブで該当箇所を直す
  • リボンのボタンが押せない(グレーアウトのまま) → 本文を選択していないと無効のまま。見出し・コピペボタン・NPC化・リンク・文字装飾のボタンは本文をドラッグ選択してから押す
  • 見出しやコピペボタンを解除したい → 設定済みの範囲を選び直し、同じボタンをもう一度押すと解除される
  • コピー操作が反応しない・失敗する → ブラウザやOSの制限でクリップボードへの書き込みができない場合がある。時間を置くか、別の対応方法(手動での書き写しなど)を検討する
  • 内部リンクをクリックしても何も起きない → 編集タブではリンクは反応しない(誤操作防止のため)。プレビュータブに切り替えてから試す
  • 編集内容を元に戻したい → リボンの「元に戻す」で直前の操作を取り消せる(最大20件)。それ以上前には戻せない
  • 読み込んだHTMLの設定が復元されない → 本ツールで書き出した「HTML」以外のファイル(Markdown・テキスト、または他ツールで作ったHTML)は設定の復元に対応していない
  • 読み込み画面に「前回の続き」が出ない → まだ一度も編集していないか、プライベートブラウズなどでブラウザの保存機能が使えない状態。またはSafariが保存データを消した可能性がある(長期間開かないと消えることがある)
  • iPhoneで書き出したHTMLがフォルダに溜まる → iPhoneでは上書き保存ができない。作業途中の保存は自動保存に任せ、書き出しは完成版だけにする
  • 「共有して保存」ボタンが出ない → HTML形式を選んでいないか、その端末・ブラウザがファイルの共有に対応していない
